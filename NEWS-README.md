# Как добавить новость на сайт

Новости на главной берутся из файла **`public/news.json`**.
Ничего в вёрстке трогать не нужно — сайт сам нарисует карточки.

## Как добавить

Откройте `public/news.json` и добавьте объект в список:

```json
[
  {
    "date": "2026-11-05",
    "title": "Вышел первый выпуск BOX",
    "text": "Рассказываем, что внутри и как заказать.",
    "link": "https://t.me/i_live_mus/123",
    "linkText": "Читать в Telegram"
  }
]
```

Поля:

| Поле | Обязательно | Что это |
|---|---|---|
| `date` | да | Дата в формате `ГГГГ-ММ-ДД`. На сайте покажется как `05.11.2026` |
| `title` | да | Заголовок карточки |
| `text` | нет | Пара предложений описания |
| `link` | нет | Ссылка на полную публикацию (Telegram, VK, YouTube) |
| `linkText` | нет | Текст ссылки. По умолчанию «Подробнее» |

## Правила

- Несколько новостей — через запятую, в квадратных скобках `[ ... ]`.
- Порядок в файле не важен: сайт сам ставит свежие сверху.
- Последняя новость **не** должна заканчиваться запятой. Запятая ставится только *между* объектами.
- Если файл пустой (`[]`), на сайте остаётся заглушка «Новости скоро».
- Если в JSON ошибка, сайт не сломается — просто покажет заглушку.

## Как проверить, что JSON без ошибок

Вставьте содержимое файла на https://jsonlint.com — он покажет ошибку, если она есть.

## После правки

Файл отправляется в репозиторий (коммит в `main`), Vercel пересобирает сайт за 1–2 минуты.
